[English]
Double-click NoJunk2.pyw in this folder to open the tool.
Requires Python 3.10 or higher (check "Add to PATH" during install).
With Python installed, .pyw opens with pythonw by default - double-click shows
the window directly, no black console, just like the exe.

Or open a terminal in this folder and run: python nojunk_ui.py

[Important: patches need a mod loader (DMM/CDUMM) to take effect]
The game does NOT read the mods/ folder by itself. The overlay patch generated
by this tool only takes effect after a mod loader (DMM/CDUMM) loads it.
If you do not use CDUMM, click "Export patch JSON" on the Global tab and import
it into CDUMM / JSON Mod Manager / DMM.

update to this version.

[Problems?]
